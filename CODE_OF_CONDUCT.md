# Código de conduta

Queremos um projeto acolhedor para pessoas de qualquer experiência, origem e identidade.

## Comportamento esperado

- Trate as pessoas com respeito e boa-fé.
- Discuta ideias e código sem ataques pessoais.
- Aceite correções e explique decisões técnicas com clareza.
- Respeite privacidade, autoria e licenças.

## Comportamento inaceitável

Assédio, discriminação, ameaças, conteúdo sexual inadequado, divulgação de dados pessoais sem consentimento, spam e ataques pessoais não serão tolerados.

## Aplicação

Este código vale para issues, pull requests, discussões e outros espaços do projeto. Os mantenedores podem editar ou remover conteúdo e restringir a participação para proteger a comunidade. Use as ferramentas privadas de denúncia do GitHub para relatar condutas abusivas e evite expor pessoas em público.
